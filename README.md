# 悠愉樹庵 公式サイト（静的ホスティング用）

このリポジトリは、Cloudflare Pages で公開する静的サイトです。  
**ブラウザだけで更新**できます（Git やローカル環境は不要）。

## フォルダ構成
- `index.html` … トップページ（ここから `/js/menu.js` を読み込み）
- `js/menu.js` … メニュー表示や動きのスクリプト
- `images/` … 画像フォルダ（店舗外観・内観・メニュー写真など）
- `README.md` … この案内

## 更新の基本ルール
1. **HTMLは基本さわらない**  
   - お知らせ・ブログ等の更新は、JSON もしくは追って用意される更新用ファイルに追記します。  
   - レイアウトや動きの修正はエンジニアが対応します。

2. **ファイル場所**  
   - 画像は必ず `images/` 内に入れる  
   - スクリプトは `js/` 内に入れる（`/js/menu.js` のパス前提）

3. **命名ルール**  
   - 半角英数字・ハイフン（`-`）・アンダースコア（`_`）のみ  
   - 日本語・空白・記号は使わない  
   - 例：`exterior-01.jpg`, `interior_table-01.webp`

4. **画像の推奨サイズ**  
   - 横幅：ヒーロー・スライダー画像は **2000px前後** を上限  
   - 通常の挿絵：**1200px** 程度  
   - 形式：写真は **JPG**、ロゴ/イラストや透過が必要なら **PNG/WEBP**  
   - 容量目安：1枚 **~300KB** を目標（最大でも 1MB 未満）  
   - 重い場合は圧縮（TinyPNG 等のオンラインツールでOK）

5. **更新フロー（最短手順）**  
   1) 画像がある場合は `images/` にアップ  
   2) 変更対象のファイルをブラウザで開き、右上の鉛筆アイコンで編集  
   3) 下部の **Commit changes** を押すだけで保存（その後 Cloudflare Pages が自動公開）

6. **トラブル時の戻し方（ロールバック）**  
   - ファイルの **History** から直前のコミットを開き、**Revert** で元に戻せます  
   - うまく戻らない場合は、リポジトリの **Commits** から該当コミットを Revert

## メニューと外国語ページの更新
- メニュー・値段・アレルゲンは `js/menu-data.js` を直します（日本語・英語・繁体字・韓国語の4つ分が1か所にあります）。
- 英語・繁体字・韓国語のページの文言は `scripts/i18n/strings.js` を直します。
- どちらかを直したら `npm run build:i18n` を実行して外国語ページ（今は `en/` のみ。繁体字と韓国語は確認待ちで公開していません）を作り直し、新しい見た目の指定を使ったときは `npm run build:css` も実行します。
- `en/index.html` を直接直さないでください（次の実行で消えます）。
- **ブラウザの編集では `npm` を実行できません。** `js/menu-data.js` をブラウザで直すと、日本語ページだけ変わり、外国語ページの値段とアレルゲンは古いまま残ります。PR の「外国語ページの確認」が失敗したら、手元で `npm run build:i18n` を実行して入れ直してください。
- 値段や品名を変えたら、`index.html` の検索向けの情報（`application/ld+json`）も手で直してください。
- CSS と JS は読み手のブラウザに最大4時間残ります。読み込み方やファイルの分け方を変えたときは、`index.html` と `scripts/build-i18n.js` の `?v=` の値を上げてください。

- **デザイン/動き調整**：エンジニア
